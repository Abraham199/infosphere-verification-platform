# SDK Foundation

Phase 10 prepares a language-neutral SDK strategy. SDKs are not generated yet.

## Strategy

- OpenAPI-first contracts.
- SDKs generated from versioned API schemas.
- Target languages: PHP, JavaScript/TypeScript, Python, and mobile clients.
- SDK major versions follow public API major versions.

## Requirements Before SDK Generation

- Stable API route inventory.
- Stable OpenAPI schema output.
- Error-code catalog.
- Authentication examples.
- Sandbox examples.
