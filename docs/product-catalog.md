# Product Catalog

The Product Engine centralizes every sellable service on IVP. Products replace hardcoded service definitions and allow verification, telecom, utilities, education, banking, government, API, marketplace, and future services to share a common catalog.

Core tables:

- `product_categories`
- `products`
- `product_provider_mappings`
- `tenant_products`
- `product_features`
- `product_capabilities`

Products define customer-facing service identity, pricing defaults, visibility, lifecycle status, and metadata. Provider mappings define fulfillment options separately.

Examples:

- NIN Verification
- BVN Verification
- Airtime
- Data
- Electricity
- Cable TV
- WAEC Result Checker
- Virtual Accounts
- API Products
